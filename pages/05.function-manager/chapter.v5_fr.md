# Gestionnaire de Fonctions

Le **Gestionnaire de Fonctions** est la liste de toutes les **fonctions** de
votre projet — Scenes, Chasers, Sequences, EFX, Collections, RGB Matrices,
Shows, Scripts, Audio et Video. Il se trouve dans le panneau droit de l'espace
de travail [Fixtures and Functions](/fixtures-and-functions) ; ouvrez-le avec
le bouton **Function Manager**.

À partir d'ici, vous sélectionnez les fonctions à modifier, les organisez en
dossiers, et filtrez ou recherchez dans la liste. Les boutons permettant de
créer, supprimer, renommer, cloner et prévisualiser les fonctions se trouvent
sur le panneau droit lui-même — voir
[Fixtures and Functions](/fixtures-and-functions).

## La liste

Les fonctions sont affichées sous forme d'arborescence. Vous pouvez les
regrouper en **dossiers** pour garder les grands projets bien organisés.

* **Cliquez** sur une fonction pour la sélectionner ; **Ctrl+clic** pour en
  sélectionner plusieurs.
* **Double-cliquez** sur une fonction pour ouvrir son éditeur. (Double-cliquer
  sur un **Show** bascule vers le Show Manager.)
* **Double-cliquez** sur un dossier pour l'étendre ou le replier.
* **Glissez** des fonctions sur un dossier pour les y déplacer ; glissez une
  fonction hors d'un dossier pour la réorganiser. Vous pouvez également
  renommer un dossier pour déplacer tout ce qu'il contient.
* **Cliquez sur une zone vide** sous la liste pour effacer la sélection.

## Filtrage par type

La barre d'outils en haut comporte un bouton à bascule pour chaque type de
fonction, chacun affichant un **compteur** du nombre de fonctions de ce type
présentes :

* **Scenes**
* **Chasers**
* **Sequences**
* **EFX**
* **Collections**
* **RGB Matrices**
* **Shows**
* **Scripts**
* **Audio**
* **Videos**

Désactivez un type pour masquer ces fonctions de la liste, ce qui facilite la
concentration sur ce sur quoi vous travaillez.

## Recherche

Le bouton de **recherche** (loupe) à droite de la barre d'outils ouvre une zone
permettant de filtrer la liste par nom de fonction.

## Modifier une fonction

Sélectionner puis modifier (ou double-cliquer sur) une fonction ouvre son
éditeur dédié dans le panneau droit. Chaque type de fonction possède son propre
éditeur — par exemple l'éditeur de Scène, l'éditeur de Chaser, l'éditeur EFX,
et ainsi de suite.
