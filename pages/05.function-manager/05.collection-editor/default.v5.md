A **Collection** runs several functions **at the same time**. Where a chaser plays its members one after another, a collection fires them all together — useful for grouping looks and effects that should always start as one. The Collection Editor opens in the right panel of the [Fixtures and Functions](/fixtures-and-functions) workspace.

## Toolbar

| Button | What it does |
|--------|--------------|
| **Name** | The collection's name (top bar). |
| <i class="fa fa-chevron-left fa-2x"></i> **Back** | Returns to the previous editor. |
| <i class="fa fa-2x fa-plus" style="color:limegreen"></i> **Add a function** | Opens the Function Manager in a side panel. Drag functions from it into the list. |
| <i class="fa fa-2x fa-minus" style="color:crimson"></i> **Remove the selected function** | Removes the selected members (asks for confirmation). |

## The function list

The main area lists the functions that belong to the collection.

| Action | Result |
|--------|--------|
| **Click** | Selects a function. |
| **Ctrl+click** / **Shift+click** | Adds to the selection / selects a range. |
| **Drag** from the Function Manager | Adds the dragged functions at the drop position. |
| **Drag** within the list | Moves a function to another position. |
| **Double-click** | Opens that function's own editor. |

The list order is only a convenience for reading and organising the collection — it does not affect playback, since every member starts at the same moment.

When the collection is triggered, every function in this list starts at once, and the collection stays active until they have all finished.
