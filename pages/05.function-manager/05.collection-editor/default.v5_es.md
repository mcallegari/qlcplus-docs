---
title: 'Editor de Colección'
date: '12:21 21-08-2023'
---

Una **Colección** ejecuta varias funciones **al mismo tiempo**. Mientras que un chaser reproduce sus miembros uno tras otro, una colección los dispara todos juntos — útil para agrupar aspectos y efectos que siempre deben iniciarse como uno solo. El Editor de Colección se abre en el panel derecho del área de trabajo [Fixtures and Functions](/fixtures-and-functions).

## Barra de herramientas

| Botón | Qué hace |
|--------|--------------|
| **Nombre** | El nombre de la colección (barra superior). |
| <i class="fa fa-chevron-left fa-2x"></i> **Atrás** | Vuelve al editor anterior. |
| <i class="fa fa-2x fa-plus" style="color:limegreen"></i> **Añadir una función** | Abre el Gestor de Funciones en un panel lateral. Arrastre funciones desde allí a la lista. |
| <i class="fa fa-2x fa-minus" style="color:crimson"></i> **Eliminar la función seleccionada** | Elimina los miembros seleccionados (pide confirmación). |

## La lista de funciones

El área principal enumera las funciones que pertenecen a la colección.

| Acción | Resultado |
|--------|--------|
| **Clic** | Selecciona una función. |
| **Ctrl+clic** / **Shift+clic** | Añade a la selección / selecciona un rango. |
| **Arrastrar** desde el Gestor de Funciones | Añade las funciones arrastradas en la posición de soltado. |
| **Arrastrar** dentro de la lista | Mueve una función a otra posición. |
| **Doble clic** | Abre el editor propio de esa función. |

El orden de la lista es solo una comodidad para leer y organizar la colección — no afecta a la reproducción, ya que todos los miembros comienzan en el mismo instante.

Cuando se activa la colección, todas las funciones de esta lista se inician a la vez, y la colección permanece activa hasta que todas hayan terminado.
