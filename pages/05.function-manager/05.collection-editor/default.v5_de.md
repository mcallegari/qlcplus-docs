Eine **Sammlung** führt mehrere Funktionen **gleichzeitig** aus. Während ein Chaser seine Mitglieder nacheinander abspielt, startet eine Sammlung sie alle zusammen — nützlich, um Looks und Effekte zu gruppieren, die immer als eine Einheit starten sollen. Der Sammlungseditor öffnet sich im rechten Bereich des Arbeitsbereichs [Fixtures and Functions](/fixtures-and-functions).

## Symbolleiste

| Schaltfläche | Was sie bewirkt |
|--------|--------------|
| **Name** | Der Name der Sammlung (obere Leiste). |
| <i class="fa fa-chevron-left fa-2x"></i> **Zurück** | Kehrt zum vorherigen Editor zurück. |
| <i class="fa fa-2x fa-plus" style="color:limegreen"></i> **Funktion hinzufügen** | Öffnet den Funktionsmanager in einem Seitenbereich. Ziehen Sie Funktionen von dort in die Liste. |
| <i class="fa fa-2x fa-minus" style="color:crimson"></i> **Ausgewählte Funktion entfernen** | Entfernt die ausgewählten Mitglieder (nach Bestätigung). |

## Die Funktionsliste

Der Hauptbereich listet die Funktionen auf, die zur Sammlung gehören.

| Aktion | Ergebnis |
|--------|--------|
| **Klick** | Wählt eine Funktion aus. |
| **Strg+Klick** / **Umschalt+Klick** | Erweitert die Auswahl / wählt einen Bereich aus. |
| **Ziehen** aus dem Funktionsmanager | Fügt die gezogenen Funktionen an der Ablageposition hinzu. |
| **Ziehen** innerhalb der Liste | Verschiebt eine Funktion an eine andere Position. |
| **Doppelklick** | Öffnet den eigenen Editor dieser Funktion. |

Die Reihenfolge in der Liste dient nur der besseren Lesbarkeit und Organisation der Sammlung — sie hat keinen Einfluss auf die Wiedergabe, da jedes Mitglied zum selben Zeitpunkt startet.

Wenn die Sammlung ausgelöst wird, starten alle Funktionen in dieser Liste gleichzeitig, und die Sammlung bleibt aktiv, bis alle beendet sind.
