Der Show-Editor ist ein Bedienfeld zur Anzeige der aktuellen Struktur einer ![](/basics/show.png) [Show](/basics/glossary-and-concepts#show), die mit dem [Show-Manager](/show-manager) erstellt wurde.  
Im Moment kann der Show-Editor eine Show nur umbenennen, was im Show-Manager nicht möglich ist.  
  
Die Baumansicht dieses Bedienfelds zeigt nützliche Informationen zur angezeigten Show, wie zum Beispiel:

* **Funktion:** der Funktionsname
* **Schritte:** die Anzahl der Schritte, aus denen eine [Sequenz](/basics/glossary-and-concepts#sequence) besteht
* **Startzeit:** der Zeitpunkt, zu dem eine Sequenz wiedergegeben wird
* **Dauer:** die Dauer der Sequenz
