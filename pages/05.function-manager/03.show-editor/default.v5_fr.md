L'Éditeur Show est un panneau qui affiche la structure actuelle d'un ![](/basics/show.png) [Show](/basics/glossary-and-concepts#show) créé avec le [Gestionnaire de Show](/show-manager).  
Pour l'instant, l'Éditeur Show peut uniquement renommer un Show, ce qui n'est pas possible dans le Gestionnaire de Show.  
  
La vue arborescente de ce panneau affiche des informations utiles concernant le Show affiché, telles que :

* **Function :** le nom de la fonction
* **Steps :** le nombre de steps qui composent une [Séquence](/basics/glossary-and-concepts#sequence)
* **Start Time :** l'instant auquel une séquence va être reproduite
* **Duration :** la durée de la séquence
