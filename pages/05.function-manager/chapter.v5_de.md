### Kapitel 4

# Funktionsmanager

Der **Funktionsmanager** ist die Liste aller **Funktionen** in Ihrem Projekt —
Szenen, Chaser, Sequenzen, EFX, Sammlungen, RGB-Matrizen, Shows, Skripte,
Audio und Video. Er befindet sich im rechten Bereich des Arbeitsbereichs
[Fixtures and Functions](/fixtures-and-functions); öffnen Sie ihn mit der
Schaltfläche **Function Manager**.

Von hier aus wählen Sie Funktionen zum Bearbeiten aus, organisieren sie in
Ordnern und filtern oder durchsuchen die Liste. Die Schaltflächen zum
Erstellen, Löschen, Umbenennen, Klonen und Anzeigen einer Vorschau von
Funktionen befinden sich im rechten Bereich selbst — siehe
[Fixtures and Functions](/fixtures-and-functions).

## Die Liste

Funktionen werden in einer Baumstruktur angezeigt. Sie können sie in
**Ordnern** gruppieren, um größere Projekte übersichtlich zu halten.

* **Klicken** Sie auf eine Funktion, um sie auszuwählen; **Strg+Klick**, um
  mehrere auszuwählen.
* **Doppelklicken** Sie auf eine Funktion, um ihren Editor zu öffnen.
  (Doppelklicken auf eine **Show** wechselt zum Show Manager.)
* **Doppelklicken** Sie auf einen Ordner, um ihn ein- oder auszuklappen.
* **Ziehen** Sie Funktionen auf einen Ordner, um sie hineinzuverschieben;
  ziehen Sie eine Funktion heraus, um neu zu organisieren. Sie können einen
  Ordner auch umbenennen, um alles darin zu verschieben.
* **Klicken** Sie auf eine leere Fläche unterhalb der Liste, um die Auswahl
  aufzuheben.

## Filtern nach Typ

Die Symbolleiste am oberen Rand enthält für jeden Funktionstyp eine
Umschaltfläche, die jeweils eine **Anzahl** zeigt, wie viele Funktionen dieses
Typs Sie haben:

* **Scenes**
* **Chasers**
* **Sequences**
* **EFX**
* **Collections**
* **RGB Matrices**
* **Shows**
* **Scripts**
* **Audio**
* **Videos**

Schalten Sie einen Typ aus, um diese Funktionen aus der Liste auszublenden,
damit Sie sich leichter auf das konzentrieren können, woran Sie gerade
arbeiten.

## Suche

Die **Such**-Schaltfläche (Lupe) rechts in der Symbolleiste öffnet ein Feld,
in dem Sie die Liste nach Funktionsnamen filtern können.

## Eine Funktion bearbeiten

Das Auswählen und anschließende Bearbeiten (oder Doppelklicken) einer
Funktion öffnet ihren dedizierten Editor im rechten Bereich. Jeder
Funktionstyp hat seinen eigenen Editor — zum Beispiel den Szeneneditor, den
Chaser-Editor, den EFX-Editor und so weiter.
