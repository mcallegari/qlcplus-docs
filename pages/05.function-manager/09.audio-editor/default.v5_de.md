Eine **Audio**-Funktion spielt eine Sounddatei ab. Sie ermöglicht es Ihnen, Musik,
Stinger und Effekte aus QLC+ heraus parallel zu Ihrer Beleuchtung auszulösen. Der
Audio-Editor öffnet sich im rechten Bereich des Arbeitsbereichs
[Fixtures and Functions](/fixtures-and-functions); wenn Sie eine Audiofunktion
erstellen, werden Sie zunächst zur Auswahl der Datei aufgefordert.

## Eigenschaften

* **Name** — der Name der Funktion (obere Leiste).
* **Dateiname** — die abzuspielende Audiodatei. Verwenden Sie die Schaltfläche
  **...**, um eine andere Datei auszuwählen.
* **Dauer**, **Kanäle**, **Abtastrate**, **Bitrate** — schreibgeschützte Details
  der ausgewählten Datei, nur zur Information.
* **Wiedergabemodus** — **Single shot** (einmalige Wiedergabe) oder **Looped**
  (Wiederholung bis zum Stoppen).
* **Ausgabegerät** — an welche Audioausgabe der Sound gesendet wird.
* **Lautstärke** — Wiedergabelautstärke, 0–100 %.
* **Einblenden** — Zeit, um den Sound beim Start einzublenden. Doppelklicken Sie
  auf das Feld oder verwenden Sie die Uhr-Schaltfläche, um sie festzulegen.
* **Ausblenden** — Zeit, um den Sound beim Stoppen auszublenden.
