Una funzione **Audio** riproduce un file audio. Consente di attivare musica, stinger
ed effetti da QLC+ insieme all'illuminazione. L'Editor Audio si apre nel pannello
destro dell'area di lavoro [Fixtures and Functions](/fixtures-and-functions); quando
si crea una funzione audio viene chiesto di scegliere prima il file.

## Proprietà

* **Name** — il nome della funzione (barra superiore).
* **File name** — il file audio da riprodurre. Usare il pulsante **...** per scegliere
  un file diverso.
* **Duration**, **Channels**, **Sample Rate**, **Bitrate** — dettagli in sola lettura
  del file selezionato, mostrati per riferimento.
* **Playback mode** — **Single shot** (riproduzione singola) oppure **Looped**
  (ripetizione fino all'arresto).
* **Output device** — a quale uscita audio viene inviato il suono.
* **Volume** — volume di riproduzione, 0–100%.
* **Fade in** — tempo di dissolvenza in entrata del suono all'avvio. Fare doppio clic
  sul campo oppure usare il pulsante a orologio per impostarlo.
* **Fade out** — tempo di dissolvenza in uscita del suono all'arresto.
