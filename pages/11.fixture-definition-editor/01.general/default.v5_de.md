Im Bereich **Allgemein** werden die allgemeinen Informationen des Fixtures
angegeben.

|     |     |
| --- | --- |
| **Hersteller** | Der Herstellername des Fixtures. Zum Beispiel „ClayPaky“. Bitte beachten Sie: Wenn Sie eine Definition für einen Hersteller hinzufügen, der bereits in der QLC+-Bibliothek vorhanden ist, sollten Sie genau denselben Namen verwenden, den auch die anderen Ersteller verwendet haben. Zum Beispiel ist „IMG Stageline“ nicht „img stageline“ oder „IMG-Stageline“. |
| **Modell** | Der Modellname des Fixtures. Zum Beispiel „Sharpy“. Bitte halten Sie sich beim Ausfüllen dieser Angabe an das Produkthandbuch. Es ist nicht nötig, die LED-Konfiguration wie „PAR64 MKII 8x1W LED RGBWAUV USB“ anzugeben — es reicht „PAR64 MKII“. |
| **Typ** | Der Kategorietyp des Fixtures, ausgewählt aus einem Symbolmenü (Color Changer, Dimmer, Effect, Fan, Flower, Hazer, Laser, LED Bar (Beams), LED Bar (Pixels), Moving Head, Other, Scanner, Smoke, Strobe). Für eine korrekte Vorschau ist es wichtig, die passende Kategorie zu wählen — auch wenn ein Moving Head zum Beispiel höchstwahrscheinlich auch ein Farbwechsler ist, sollte sein Typ auf „Moving Head“ gesetzt werden. |
| **Autor** | Der Name des Autors der Fixture-Definition. Bitte geben Sie keine E-Mail-Adressen oder Verweise auf eine Website an — sie werden bei der Überprüfung ohnehin entfernt. |
