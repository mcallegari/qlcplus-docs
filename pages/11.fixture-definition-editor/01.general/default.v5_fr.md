La section **General** est l'endroit où sont fournies les informations
générales du fixture.

|     |     |
| --- | --- |
| **Manufacturer** | Le nom du fabricant du fixture. Par exemple « ClayPaky ». Notez que si vous ajoutez une définition d'un fabricant déjà présent dans la bibliothèque de QLC+, vous devez utiliser exactement le même nom adopté par les autres créateurs. Par exemple, « IMG Stageline » n'est pas « img stageline » ni « IMG-Stageline ». |
| **Model** | Le nom du modèle du fixture. Par exemple « Sharpy ». Veuillez vous en tenir au manuel du produit pour renseigner cette information. Inutile de préciser la configuration LED comme « PAR64 MKII 8x1W LED RGBWAUV USB » — il suffit d'indiquer « PAR64 MKII ». |
| **Type** | Le type de catégorie du fixture, choisi dans un menu d'icônes (Color Changer, Dimmer, Effect, Fan, Flower, Hazer, Laser, LED Bar (Beams), LED Bar (Pixels), Moving Head, Other, Scanner, Smoke, Strobe). Pour un aperçu précis, il est important de choisir la catégorie appropriée — par exemple, bien qu'une lyre soit très probablement aussi un changeur de couleur, son type doit être défini sur « Moving Head ». |
| **Author** | Le nom de l'auteur de la définition du fixture. Merci de ne pas saisir d'adresses e-mail ni de références à un site web — elles sont de toute façon supprimées lors de la relecture. |
