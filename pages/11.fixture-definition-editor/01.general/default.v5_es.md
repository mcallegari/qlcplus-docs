La sección **General** es el lugar donde se proporciona la información
general del fixture.

|     |     |
| --- | --- |
| **Manufacturer** | El nombre del fabricante del fixture. Por ejemplo, "ClayPaky". Tener en cuenta que, si se añade una definición de un fabricante ya presente en la biblioteca de QLC+, se debe utilizar exactamente el mismo nombre adoptado por los demás autores. Por ejemplo, "IMG Stageline" no es "img stageline" ni "IMG-Stageline". |
| **Model** | El nombre del modelo del fixture. Por ejemplo, "Sharpy". Atenerse al manual del producto para completar esta información. No es necesario especificar la configuración LED como "PAR64 MKII 8x1W LED RGBWAUV USB" — basta con "PAR64 MKII". |
| **Type** | El tipo de categoría del fixture, elegido en un menú de iconos (Color Changer, Dimmer, Effect, Fan, Flower, Hazer, Laser, LED Bar (Beams), LED Bar (Pixels), Moving Head, Other, Scanner, Smoke, Strobe). Para una vista previa precisa es importante elegir la categoría correcta — por ejemplo, aunque una cabeza móvil probablemente también sea un cambiacolores, su tipo debería establecerse como "Moving Head". |
| **Author** | El nombre del autor de la definición del fixture. Se recomienda no introducir direcciones de correo electrónico ni referencias a un sitio web — de todos modos se eliminan durante la revisión. |
