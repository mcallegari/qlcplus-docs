La sezione **Physical properties** è il luogo in cui vengono fornite le
informazioni fisiche _globali_ del fixture.<br>
Lo stesso insieme di proprietà è disponibile anche all'interno di ciascuna
**modalità**, nel caso in cui le caratteristiche fisiche del fixture (ad
esempio l'intervallo di pan/tilt) cambino a seconda della modalità. In quel
caso è possibile scegliere **Use global settings** oppure **Override global
settings** con valori specifici per la modalità (vedere [Modes](../modes)).

|     |     |
| --- | --- |
| **Bulb** | * **Type**: il tipo di sorgente luminosa effettiva all'interno del fixture.<br>* **Lumens**: la potenza luminosa totale della sorgente luminosa, in lumen.<br>* **Colour Temp (K)**: la temperatura colore della sorgente luminosa, in [Kelvin](https://it.wikipedia.org/wiki/Kelvin). |
| **Lens** | * **Name**: il tipo/nome della lente, se applicabile.<br>* **Min Degrees**: l'angolo minimo del fascio del fixture, in [gradi](https://it.wikipedia.org/wiki/Grado_(angolo)).<br>* **Max Degrees**: l'angolo massimo del fascio del fixture, in [gradi](https://it.wikipedia.org/wiki/Grado_(angolo)). |
| **Head(s)** | * **Pan Max Degrees**: l'ampiezza massima del pan, in [gradi](https://it.wikipedia.org/wiki/Grado_(angolo)).<br>* **Tilt Max Degrees**: l'altezza massima del tilt, in [gradi](https://it.wikipedia.org/wiki/Grado_(angolo)).<br>* **Layout (Columns x Rows)**: per i fixture a pixel/matrice, la disposizione delle sorgenti luminose come griglia di colonne per righe. |
| **Electrical** | * **Power Consumption**: il consumo energetico totale del fixture, in [Watt](https://it.wikipedia.org/wiki/Watt).<br>* **DMX Connector**: il tipo di connettore DMX del fixture. |
| **Dimensions** | * **Weight**: il peso totale del fixture, in [chilogrammi](https://it.wikipedia.org/wiki/Chilogrammo).<br>* **Width**: la larghezza orizzontale totale del fixture, in [millimetri](https://it.wikipedia.org/wiki/Millimetro).<br>* **Height**: l'altezza verticale totale del fixture, in [millimetri](https://it.wikipedia.org/wiki/Millimetro).<br>* **Depth**: la profondità totale del fixture, in [millimetri](https://it.wikipedia.org/wiki/Millimetro). |
