Ein **Animation**-Widget spielt eine [RGB-Matrix](/function-manager/rgb-matrix-editor)-Funktion
ab und steuert sie, sodass Sie deren **Farben** live ändern und ihre
**Muster-Voreinstellung** live umschalten können. Es ist die Bedienoberfläche
für Pixel-/LED-Effekte in der [virtuellen Konsole](/virtual-console).

Weisen Sie eine RGB-Matrix-Funktion zu, indem Sie sie auf das Widget ziehen
oder über die Einstellungen.

## Einstellungen

* **Zugewiesene Funktion** — die RGB-Matrix, die dieses Widget steuert. Mit
  **Aktuelle Funktion trennen** wird die Zuweisung entfernt.
* **Farb- und Voreinstellungsänderungen sofort anwenden** — wenn aktiviert,
  wirken sich Farb- oder Voreinstellungsänderungen sofort aus; wenn deaktiviert,
  werden sie erst beim nächsten Start der Funktion angewendet.

### Erscheinungsbild

Wählen Sie, welche Steuerelemente das Widget anzeigt:

* **Pegel-Fader** — ein Fader für die Intensität der Matrix.
* **Beschriftung** — die Textbeschriftung des Widgets.
* **Farbtasten 1–5** — Farbtasten, die die Farben der Matrix live festlegen
  (wie viele davon sinnvoll sind, hängt vom Muster ab).
* **Voreinstellungsliste** — eine Liste zum Umschalten von Muster/Algorithmus
  der Matrix im laufenden Betrieb.

## Voreinstellungen

Das Animation-Widget verfügt über eine Registerkarte **Voreinstellungen**, auf
der Sie die Liste der auswählbaren Voreinstellungen erstellen:

* **Voreinstellung mit fester Farbe hinzufügen** für einen gewählten Farbslot.
* **R/G/B-Regler hinzufügen** für einen Farbslot (Live-Farbmischung).
* **Skript-Algorithmus-Voreinstellung hinzufügen** (wählen Sie einen der
  Matrix-Algorithmen).
* **Text-Voreinstellung hinzufügen** mit von Ihnen eingegebenem Text.
* Voreinstellungen mit **nach oben / nach unten verschieben** neu anordnen
  oder **entfernen**.

## Tipps

* Erstellen Sie eine **Voreinstellungsliste** Ihrer bevorzugten Looks für eine
  Matrix, damit ein Bediener mit einem einzigen Tastendruck zwischen ihnen
  wechseln kann.
* Aktivieren Sie **Änderungen sofort anwenden** für eine unmittelbare,
  improvisierte Farbsteuerung.
