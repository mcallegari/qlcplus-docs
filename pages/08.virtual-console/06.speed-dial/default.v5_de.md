Eine **Speed Dial** (Kurzwahl) stellt live das **Timing** von Funktionen ein
und passt es an — die Einblend-, Ausblend- und Dauerzeiten. Verwenden Sie sie,
um Chaser und Effekte spontan schneller oder langsamer zu machen, oft im Takt
der Musik angetippt. Sie gehört zur [virtuellen Konsole](/virtual-console).

## Einstellungen

### Funktionen

Die Liste der Funktionen, deren Timing dieses Rad steuert. **Ziehen Sie**
Funktionen per Drag & Drop auf das Widget, um sie hinzuzufügen. Für jede
Funktion legen Sie fest, welche ihrer Zeiten das Rad steuert:

* **Einblendfaktor**
* **Ausblendfaktor**
* **Dauerfaktor (+Tap)** — die Dauer, die auch durch Antippen eingestellt
  werden kann.

Jeder Faktor kann **(Nicht gesendet)** sein oder ein Multiplikator:
**0, 1/16, 1/8, 1/4, 1/2, 1, 2, 4, 8, 16** — sodass ein Rad zum Beispiel eine
Funktion mit halber Geschwindigkeit und eine andere mit doppelter
Geschwindigkeit laufen lassen kann. Mit **Diese Funktion entfernen** entfernen
Sie eine Funktion aus der Liste.

### Rad-Eigenschaften

* **Multiplikatorfaktor zurücksetzen, wenn sich der Radwert ändert** — setzt
  den angewendeten Multiplikator zurück, sobald Sie eine neue Zeit am Rad
  einstellen.
* **Zeitbereich des Rads** — die Grenzen **von / bis** der Zeit, die das Rad
  einstellen kann.

### Erscheinungsbild

Wählen Sie, welche Steuerelemente das Widget anzeigt:

* **+/- Tasten** — Erhöhen-/Verringern-Tasten.
* **Rad** — das Drehrad.
* **Tap** — eine Tap-Taste, um die Zeit durch Antippen eines Tempos
  einzustellen.
* **Multiplikatoren** — Tasten zum Anwenden von ×/÷-Multiplikatoren.
* **Anwenden** — eine Anwenden-Taste.

### Multiplikatoren / Zeiteinheiten

Das Rad kann in **Stunden**, **Minuten**, **Sekunden**, **Millisekunden** oder
**Beats** arbeiten, sodass es sowohl als präzise Zeiteinstellung als auch als
beat-synchrone Tempo-Steuerung dienen kann.

## Tipps

* Stellen Sie die Zeiteinheit auf **Beats** und verwenden Sie **Tap**, um
  Chaser auf das Tempo der Musik zu synchronisieren.
* Weisen Sie mehrere Funktionen mit unterschiedlichen Multiplikatorfaktoren zu,
  um eine ganze Gruppe von Effekten mit einem Rad zu fahren.
