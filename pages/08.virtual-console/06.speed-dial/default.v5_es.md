Un **Speed Dial** establece y regula en vivo el **timing** de las funciones
— los tiempos de fade in, fade out y duración. Se usa para acelerar o
ralentizar chases y efectos sobre la marcha, a menudo marcando el ritmo al
compás de la música. Pertenece a la [Virtual Console](/virtual-console).

## Settings

### Functions

La lista de funciones cuyo timing controla esta perilla. **Arrastrar** las
funciones sobre el widget para añadirlas. Para cada función se elige cuál de
sus tiempos es pilotado por la perilla:

* **Fade In Factor**
* **Fade Out Factor**
* **Duration Factor (+tap)** — la duración, que también puede establecerse
  marcando el ritmo (tap).

Cada factor puede ser **(Not sent)** o un multiplicador: **0, 1/16, 1/8,
1/4, 1/2, 1, 2, 4, 8, 16** — de modo que una sola perilla puede, por
ejemplo, hacer correr una función a media velocidad y otra al doble. Usar
**Remove this function** para eliminar una función de la lista.

### Dial Properties

* **Reset multiplier factor when the dial value changes** — restablece el
  multiplicador aplicado cada vez que se establece un nuevo tiempo en la
  perilla.
* **Dial time range** — los límites **from / to** del tiempo que se puede
  establecer con la perilla.

### Appearance

Elegir qué controles muestra el widget:

* **+/- Buttons** — botones de incremento/decremento.
* **Dial** — la perilla giratoria.
* **Tap** — un botón tap para establecer el tiempo marcando un ritmo.
* **Multipliers** — botones para aplicar multiplicadores ×/÷.
* **Apply** — un botón de aplicar.

### Multipliers / time units

La perilla puede funcionar en **Hours**, **Minutes**, **Seconds**,
**Milliseconds** o **Beats**, por lo que puede ser tanto un ajustador de
tiempo preciso como un control de tempo sincronizado a compás.

## Consejos

* Establecer la unidad de tiempo en **Beats** y usar **Tap** para sincronizar
  los chases con el tempo de la música.
* Asignar varias funciones con distintos factores multiplicadores para
  gobernar todo un grupo de efectos desde una sola perilla.
