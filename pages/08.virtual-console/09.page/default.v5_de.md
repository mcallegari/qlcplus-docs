Eine **Page** (Seite) ist eine Oberfläche der [virtuellen Konsole](/virtual-console).
Die Konsole kann mehrere Seiten haben — wechseln Sie zwischen ihnen mit den
Reitern in der Symbolleiste — sodass Sie eine große Show in überschaubare
Bildschirme gliedern können (zum Beispiel eine Seite pro Song oder eine pro
Bühnenbereich).

Anders als die übrigen Einträge in diesem Kapitel ist eine Seite kein Widget,
das Sie auf die Konsole ziehen: Seiten existieren bereits als Reiter oben.
Ihre Einstellungen erreichen Sie, indem Sie den **Bearbeitungsmodus** aktivieren,
ohne dass ein Widget ausgewählt ist, sodass das rechte Panel die eigenen
Eigenschaften der Seite anzeigt.

## Einstellungen

| Einstellung | Was sie bewirkt |
|---------|--------------|
| **Breite** | Die Breite der Seitenfläche, in Pixeln. Wählen Sie sie groß genug für alle Widgets, die Sie platzieren möchten, oder passen Sie sie an die Auflösung eines Touchscreens an. |
| **Höhe** | Die Höhe der Seitenfläche, in Pixeln. |
| <i class="fa fa-lock"></i> **Sicherheit → PIN festlegen** | Schützt die Seite mit einer PIN. Ist eine PIN gesetzt, wird beim Wechsel zur Seite zuerst danach gefragt, sodass sensible Steuerelemente während einer Show gesperrt werden können. |

## Seiten verwalten

| Schaltfläche | Was sie bewirkt |
|--------|--------------|
| **Seite links hinzufügen** | Fügt unmittelbar vor der aktuellen eine neue, leere Seite ein. |
| **Seite rechts hinzufügen** | Fügt unmittelbar nach der aktuellen eine neue, leere Seite ein. |
| <i class="fa fa-trash" style="color:crimson"></i> **Diese Seite löschen** | Entfernt die aktuelle Seite und alle darauf befindlichen Widgets (nach einer Sicherheitsabfrage). |

## Wechseln und Abtrennen

* **Linksklick** auf einen Seitenreiter in der Symbolleiste, um diese Seite
  anzuzeigen.
* **Rechtsklick** auf einen Seitenreiter, um sie in ein eigenes Fenster
  **abzutrennen** — nützlich, um eine Seite auf einem zweiten Bildschirm oder
  Touchscreen anzuzeigen.

## Tipps

* Geben Sie jeder Seite einen aussagekräftigen Namen (bearbeiten Sie die
  Beschriftung des Reiters), damit ein Bediener während einer Show schnell den
  richtigen Bildschirm findet.
* Verwenden Sie eine **PIN** für Seiten, die Einrichtungs- oder
  Master-Steuerelemente enthalten, die während der Show nicht berührt werden
  sollen.
