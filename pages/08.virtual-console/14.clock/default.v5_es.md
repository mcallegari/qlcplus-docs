Un widget **Clock** muestra la hora en la [Virtual Console](/virtual-console)
— como reloj en curso, cronómetro o cuenta atrás — y puede **programar
funciones** para iniciarse y detenerse a horas establecidas. Se usa para
espectáculos temporizados y no atendidos (por ejemplo un escaparate de museo
o de tienda que sigue un horario diario).

## Settings

### Clock type

* **Clock** — muestra la hora actual del día.
* **Stopwatch** — cuenta hacia arriba desde cero; útil para cronometrar un
  espectáculo en curso.
* **Countdown** — cuenta hacia atrás hasta cero desde un tiempo establecido.
* **Schedule** — ejecuta funciones según una lista de horas programadas
  (abajo).

### Schedule *(tipo Schedule)*

Construye una lista de eventos temporizados. Para cada entrada de la
programación:

* **Add a function schedule** — asocia una función a una nueva entrada de
  programación.
* **Start time** — cuándo se inicia la función.
* **Stop time** — cuándo se detiene (habilitarlo con **Enable the stop
  time**; sin él, la función simplemente se inicia a la hora de comienzo).
* **Days / Repeat weekly** — elegir los días de la semana en los que se
  ejecuta la programación, de modo que un evento pueda repetirse, por
  ejemplo, cada día laborable.
* **Remove this schedule** — elimina una entrada.

Usar **Add a new schedule** para añadir más entradas.

## Consejos

* Usar **Schedule** con **Repeat weekly** para gestionar automáticamente la
  iluminación de un local según un horario recurrente.
* Usar **Countdown** en el escenario como temporizador visible para cambios
  de escenografía o el final de un intermedio.
