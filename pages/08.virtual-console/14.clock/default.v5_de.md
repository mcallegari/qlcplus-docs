Ein **Uhr**-Widget zeigt Zeit in der [virtuellen Konsole](/virtual-console) an
— als laufende Uhr, Stoppuhr oder Countdown — und kann **Funktionen zeitlich
planen**, damit sie zu festgelegten Zeiten starten und stoppen. Es wird für
zeitgesteuerte und unbeaufsichtigte Shows verwendet (z. B. ein Museum oder ein
Schaufenster, das nach einem täglichen Zeitplan läuft).

## Einstellungen

### Uhrtyp

* **Uhr** — zeigt die aktuelle Tageszeit an.
* **Stoppuhr** — zählt ab null aufwärts; nützlich, um eine laufende Show zu
  stoppen.
* **Countdown** — zählt von einer festgelegten Zeit auf null herunter.
* **Zeitplan** — führt Funktionen gemäß einer Liste geplanter Zeiten aus
  (siehe unten).

### Zeitplan *(Typ „Zeitplan“)*

Erstellen Sie eine Liste zeitgesteuerter Ereignisse. Für jeden
Zeitplaneintrag:

* **Funktionszeitplan hinzufügen** — weist einem neuen Zeitplaneintrag eine
  Funktion zu.
* **Startzeit** — wann die Funktion startet.
* **Stoppzeit** — wann sie stoppt (aktivieren Sie sie mit **Stoppzeit
  aktivieren**; ohne diese startet die Funktion einfach zur Startzeit).
* **Tage / Wöchentlich wiederholen** — wählen Sie die Wochentage, an denen der
  Zeitplan läuft, sodass sich ein Ereignis zum Beispiel an jedem Werktag
  wiederholen kann.
* **Diesen Zeitplan entfernen** — löscht einen Eintrag.

Verwenden Sie **Neuen Zeitplan hinzufügen**, um weitere Einträge hinzuzufügen.

## Tipps

* Verwenden Sie **Zeitplan** mit **Wöchentlich wiederholen**, um die
  Beleuchtung eines Veranstaltungsorts automatisch nach einem
  wiederkehrenden Zeitplan laufen zu lassen.
* Verwenden Sie **Countdown** auf der Bühne als sichtbaren Timer für
  Umbaupausen oder das Ende einer Pause.
