### ¿Qué es QLC+?

QLC+ es un software potente y fácil de usar diseñado para el control de iluminación. Ya sea que sea un profesional de la iluminación experimentado o que recién esté comenzando, QLC+ le permite controlar sus aparatos de iluminación con facilidad. El objetivo principal de este proyecto es llevar QLC+ al nivel del software comercial disponible. QLC+ representa un enfoque de desarrollo de software impulsado por la comunidad, ya que es orgullosamente de código abierto.

Puede usar QLC+ en Linux, Windows (10+), macOS (10.13+) y Raspberry Pi.

### ¿Qué significa "código abierto"?
Ser de código abierto significa que QLC+ se desarrolla de forma colaborativa y pública. El código fuente de QLC+ está disponible libremente para que cualquiera pueda verlo, modificarlo y distribuirlo. Este enfoque fomenta la innovación mediante la resolución colectiva de problemas. Usuarios de todo el mundo contribuyen a su desarrollo, garantizando que QLC+ evolucione y mejore continuamente.

### ¿Por qué considerar hacer una donación?
QLC+ está disponible para usted sin costo alguno, pero desarrollar y mantener un proyecto de esta envergadura implica una considerable cantidad de tiempo y recursos. Sus donaciones desempeñan un papel crucial para mantener QLC+ activo y receptivo a las necesidades de sus usuarios. Al donar, ayuda a garantizar que el proyecto siga desarrollándose, que los errores se corrijan con rapidez y que el soporte siga estando disponible y sea gratuito para todos.

Dependemos de las contribuciones de usuarios como usted. Cada donación, sin importar su tamaño, marca la diferencia. Si le resulta útil QLC+ o disfruta usándolo, considere apoyar nuestro trabajo con una donación. Su apoyo es muy apreciado y contribuye directamente al futuro de QLC+.

Puede contribuir a través de [GitHub Sponsorship](https://github.com/sponsors/mcallegari) o comprando [merchandising oficial.](https://merch.qlcplus.org) También puede donar a través de PayPal; visite [qlcplus.org](https://www.qlcplus.org/) para obtener más información.

### ¿Puedo contribuir de otra manera?

Si no dispone de medios para donar, existen otras formas de contribuir a QLC+, entre ellas:

1. Participar en el [foro oficial de QLC+](https://www.qlcplus.org/forum/)
2. Sugerir mejoras a esta documentación (vea el botón "Edit this page" en la parte superior derecha)
3. Ayudar a traducir QLC+ a su idioma. Consulte [esta página](https://github.com/mcallegari/qlcplus/wiki/How-to-translate-QLC-plus-in-your-language) para obtener más información.
4. Hablarles a sus amigos sobre QLC+
5. ¡Usar QLC+ para sus proyectos!

### ¡Advertencia de seguridad!
QLC+ no está diseñado ni certificado para aplicaciones críticas de seguridad como pirotecnia, efectos de llama, chorros de CO₂ o elementos escénicos motorizados. Aunque QLC+ puede controlar estos dispositivos, no proporciona bloqueos de seguridad, bloqueo de canales ni mecanismos a prueba de fallos. Su ordenador puede bloquearse o comportarse de forma impredecible bajo determinadas condiciones.

QLC+ se ha utilizado con éxito en espectáculos láser. Esto generalmente es aceptable, siempre que sus láseres incluyan protección de escaneo de público basada en hardware y cumplan con todas las normativas de seguridad pertinentes.

El uso de QLC+ para efectos de alto riesgo se realiza enteramente bajo su propia responsabilidad. Asegúrese siempre de contar con un sistema de seguridad completamente independiente y basado en hardware, y nunca confíe únicamente en el control por software para efectos potencialmente peligrosos.
