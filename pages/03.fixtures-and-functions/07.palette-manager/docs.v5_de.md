Der **Palette Manager** listet die **Paletten** in Ihrem Projekt auf und ermöglicht es Ihnen,
sie zu erstellen, zu bearbeiten und zu löschen. Öffnen Sie ihn über die Schaltfläche **Palettes** im linken
Panel des [Fixtures and Functions](/fixtures-and-functions)-Arbeitsbereichs.

Eine Palette ist ein gespeicherter, wiederverwendbarer Wert einer bestimmten Art — ein Intensitätspegel,
eine Farbe, eine Pan-/Tilt-Position oder eine 3D-Position —, den Sie auf Fixtures anwenden
und aus Ihren Funktionen heraus referenzieren können. Das Ändern einer Palette aktualisiert sie überall dort,
wo sie verwendet wird.

## Die Liste

Der Hauptbereich listet jede Palette auf, jeweils mit einem Symbol für ihren Typ und ihrem Namen.

* **Klicken** Sie auf eine Palette, um sie auszuwählen; **Strg+Klick**, um mehrere auszuwählen.
* **Ziehen** Sie eine Palette auf Fixtures oder andere Ziele, um sie anzuwenden.
* **Doppelklicken** Sie auf eine Palette, um ihr Bearbeitungswerkzeug zu öffnen (siehe unten).

## Nach Typ filtern

Die Symbolleiste oben enthält eine Umschaltfläche pro Palettentyp. Jede zeigt eine
**Anzahl** der vorhandenen Paletten dieses Typs an, und das Umschalten filtert die
Liste:

* **Intensity** — Dimmerpegel.
* **Color** — Farben (RGB / CMY / WAUV).
* **Position** — Pan-/Tilt-Positionen.
* **3D Position** — als Punkt auf der 3D-Bühne definierte Positionen.

Die **Such**-Schaltfläche (Lupe) öffnet ein Feld, um die Liste nach Palettennamen zu filtern.

## Eine Palette erstellen und bearbeiten

**Doppelklicken** Sie auf eine Palette, um das passende Werkzeug über der Liste zu öffnen, in dem
Sie ihren Wert anpassen können:

* Intensity-Paletten öffnen das **Intensity**-Werkzeug.
* Color-Paletten öffnen das **Color**-Werkzeug.
* Position-Paletten öffnen das **Position**-Werkzeug.
* Zoom-Paletten öffnen das **Beam**-Werkzeug.
* 3D-Position-Paletten öffnen das **3D Position**-Werkzeug.

Passen Sie den Wert im Werkzeug an und schließen Sie es, um die Änderung in der Palette zu speichern.

## Paletten löschen

Wählen Sie eine oder mehrere Paletten aus und klicken Sie auf die Schaltfläche **－ Delete** (rotes Minus). Ein
Bestätigungsdialog listet die Paletten auf, die entfernt werden sollen; bestätigen Sie, um sie
zu löschen.
