Introduction
--------------

Le plugin de sortie Velleman prend en charge l'interface [Velleman](https://www.velleman.eu/locale/) K8062D sur les systèmes d'exploitation Windows.

Prérequis
--------------

### Windows

Vous devez copier le fichier propriétaire Velleman [K8062D.dll](https://www.qlcplus.org/misc/K8062DLL_mod1.zip) dans le dossier principal de QLC+ (par ex. C:\\QLC+).
