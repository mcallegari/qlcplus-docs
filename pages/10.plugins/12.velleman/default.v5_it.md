Introduzione
--------------

Il plugin di output Velleman supporta l'interfaccia [Velleman](https://www.velleman.eu/locale/) K8062D sui sistemi operativi Windows.

Requisiti
--------------

### Windows

Dovete copiare il file proprietario Velleman [K8062D.dll](https://www.qlcplus.org/misc/K8062DLL_mod1.zip) nella cartella principale di QLC+ (es. C:\\QLC+).
